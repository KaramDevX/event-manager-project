# Event / Recipe / Media Manager

## Project Overview
This application is a comprehensive management tool developed as a collaborative student project. The system allows users to manage events, track attendance, perform advanced search/filter operations, and handle data persistence with built-in analytics.

**Project Duration:** February 20, 2026 – May 22, 2026  
**Status:** Phase 2 - Version Control & Branching

## Core Features
The application implements 12 distinct features distributed across four key domains:

### 1. Event Management (Ibrahim Saba)
* **Create Event:** Validation and storage of event details.
* **Delete Event:** Cascade operations for attendee cleanup.
* **List Events:** Retrieval and formatted display.

### 2. Attendance Management (Telman Hashimzada)
* **Register Attendee:** Capacity checking and duplicate prevention.
* **Cancel Registration:** Real-time updates to event capacity.
* **Show Attendees:** Statistical overview of event participants.

### 3. Search & Filter Operations (Abdelrahman Almahameed)
* **Date Filtering:** Querying events within specific time ranges.
* **Name Search:** Pattern matching for event retrieval.
* **Capacity Visualization:** Real-time monitoring of available slots.

### 4. Persistence & Analytics (Karam Hamad)
* **Save/Load:** File I/O support for JSON/CSV formats.
* **Attendance Statistics:** Data visualization and popularity ranking.
* **Reminders:** Notification system for upcoming events.
